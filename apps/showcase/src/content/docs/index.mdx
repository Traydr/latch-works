# Latch Works documentation

Latch Works is a private media archive toolchain. The same path-preserving folder layout flows from collection on the web, through local desktop browsing, explicit sync, and authenticated web viewing.

## Pipeline

1. **Gather Box** collects galleries and story PDFs from supported sites into inferred local folders.
2. **Frame View** is the desktop gallery for browsing, verifying, and organizing the archive on disk.
3. **Lockstep** scans the local tree, diffs against Pane View, and explicitly pushes changed originals.
4. **Pane View** indexes synced media and serves an authenticated, read-focused web gallery.

## Principles

- **Local-first** — the archive on disk stays authoritative.
- **Explicit sync** — Lockstep never mirrors silently; writes require intent.
- **Private delivery** — Pane View thumbnails and previews resolve through signed URLs.
