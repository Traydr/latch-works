# Search and filters

Pane View search runs against indexed media in your synced library, not against unsynced local files.

## Search

Type part of a filename or path into the search box in the header (on phones, tap the search icon to open the search sheet) and press Enter. Matching is case-insensitive; folders match by name.

Search is **library-wide**: it is not limited to the current folder or recursive mode. Recursive mode only affects normal browsing, not search scope.

Results appear as a normal grid of matching folders and media. Select or open them like any other grid item.

## Sort modes

Change sort order from the floating toolbar:

- A-Z / Z-A by name
- Newest / Oldest by file modification time
- Random, with a **Shuffle** button to reshuffle

Sort affects display order only.

## Filters

- **Show images** and **Show videos** in Settings control which media types the grid shows.
- **Exclude** in the floating toolbar leaves chosen subfolders out of recursive and comic views.

## Empty results

If search returns nothing:

- Confirm Lockstep pushed the files you expect
- Check for typos in path segments (underscores vs spaces)
- Push again. Each file is searchable as soon as its upload completes.
