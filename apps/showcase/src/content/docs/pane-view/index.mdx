# Pane View

Pane View is the web gallery for media you synced with Lockstep. Browse folders, read comics, watch videos, and open PDF stories from desktop, iPad, or iPhone — all behind sign-in.

![Pane View gallery](/screenshots/pane-view/gallery.png)

## Role in the workflow

Pane View is the **view** step:

1. Gather Box collects to disk.
2. Frame View verifies locally.
3. Lockstep pushes originals.
4. Pane View indexes and serves what arrived.

It does not watch your local folder for changes. Run Lockstep again when the archive updates.

## What matches Frame View

- Folder grid and breadcrumb navigation
- Comic mode for sequential folders
- Viewer with keyboard navigation
- Sort modes and recursive folder scanning
- Detail panel for selected items

## What is different

- Requires sign-in
- Shows only synced media
- Thumbnails and previews use signed delivery links
- Responsive layout for phones and tablets
