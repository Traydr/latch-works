# Mobile browsing

Pane View adapts the same gallery and viewer for phones and tablets.

## Layout

- The folder sidebar collapses behind a menu or sheet on narrow screens.
- The grid uses fewer columns with larger touch targets.
- A floating toolbar keeps search, sort, comic mode, and settings reachable by thumb.
- The desktop **detail panel** is hidden on mobile.

## Touch navigation

- A single tap opens folders, media, comics, or PDFs.
- Use on-screen viewer controls (and Q/E with a keyboard) to move between items.
- There is no pull-to-refresh gesture — use the toolbar refresh control if cells look stale.

## iPad

Tablets show more columns and may keep the sidebar visible in landscape. Keyboard shortcuts still work with an attached keyboard — same keys as desktop.

## iPhone

Prefer Wi‑Fi for first load of large folders so thumbnails can populate. Signed preview URLs refresh; a stale cell usually fixes itself after refreshing the folder or revisiting it.

## Session length

Mobile browsers may discard session cookies aggressively. If you are signed out unexpectedly, sign in again — your synced library is unchanged.
