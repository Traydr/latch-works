# Mobile browsing

Pane View adapts the same gallery and viewer for phones and tablets.

## Layout

- The folder sidebar collapses behind a menu or sheet on narrow screens.
- The grid uses fewer columns with larger touch targets.
- A floating toolbar keeps search, sort, and settings reachable by thumb.

## Touch navigation

- Tap to select; double-tap or use the open action to enter the viewer.
- Swipe gestures in the viewer move between pages for comics and stills where enabled.
- Pinch-to-zoom may apply to large images depending on viewer mode.

## iPad

Tablets show more columns and may keep the sidebar visible in landscape. Keyboard shortcuts still work with an attached keyboard — same keys as desktop.

## iPhone

Prefer Wi‑Fi for first load of large folders so thumbnails can populate. Signed preview URLs refresh; a stale cell usually fixes itself after pull-to-refresh or revisiting the folder.

## Session length

Mobile browsers may discard session cookies aggressively. If you are signed out unexpectedly, sign in again — your synced library is unchanged.
