# Pane View browsing

After sign-in, Pane View presents your synced library as a folder tree and media grid.

![Pane View sign-in](/screenshots/pane-view/login.png)

## Sign in

Open your Pane View URL and enter the credentials configured for your library. Sessions stay signed in until you log out or cookies expire.

Failed sign-in usually means wrong password or account — not a sync token issue. Sync tokens are for Lockstep only.

## Folder navigation

- Use the sidebar or path controls to move between folders.
- The grid shows thumbnails for images and videos in the current folder.
- On desktop, select an item to open the **detail panel** with metadata and a larger preview. The detail panel is not shown on mobile.

## Open folders and media

- Click a folder entry to descend.
- On desktop, double-click or press Enter / F on media to open the viewer.
- On mobile, a single tap opens folders, media, or comics.
- Shift+W goes to the parent folder; Shift+S opens the focused folder (with a keyboard).

## Recursive mode

Toggle recursive scanning to flatten subfolders into one grid — useful for finding recent uploads across a creator tree. Turn it off when you want strict single-folder browsing.

## Comic mode

Toggle **Comic** in the floating toolbar to group image folders into comic entries (forces recursive scanning), similar to Frame View’s Comic control.

## Read-only by design

Pane View does not edit files on disk or upload from the browser. Add media locally, then plan and push with Lockstep.
