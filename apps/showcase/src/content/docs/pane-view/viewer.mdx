# Pane View viewer

The viewer covers images, GIFs, videos, PDF stories, and comic folders synced from your archive.

![Pane View fullscreen viewer](/screenshots/pane-view/viewer.png)

## Opening media

From the grid, double-click or press Enter / F on desktop; tap on mobile. Escape closes the viewer or nested overlays.

## Still images and GIFs

Images scale to fit the viewport. Animated GIFs play in the viewer loop.

## Video

| Control | Keys |
| --- | --- |
| Play / pause | Space or 2 |
| Seek backward | 1 |
| Seek forward | 3 |
| Temporary speed boost | Hold 4 |

## Comics

With **Comic** mode on, image folders open in a page-turn reader. Use **Q** / **E** or arrows for previous and next pages.

## PDF stories

PDF entries open in an embedded reader with page navigation. When remember-position is enabled (default), page position persists across sessions via saved viewer state — not only for the current browser tab.

## Keyboard summary

| Keys | Action |
| --- | --- |
| Q / E | Previous / next item or page |
| Escape | Close viewer |
| Space / 2 | Play or pause video |
| 1 / 3 | Seek backward / forward |
| Hold 4 | Temporary speed boost |
| ? | Shortcuts overlay |

See [Keyboard shortcuts](/docs/keyboard-shortcuts) for the full gallery and viewer table.
