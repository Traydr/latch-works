# Pane View troubleshooting

## Login failure

**Symptom:** Credentials rejected or immediate redirect back to login.

**Fix:**

- Confirm username and password with your library operator.
- After 5 failed attempts within 5 minutes, sign-in is blocked and still reports invalid credentials. Wait five minutes before retrying.
- Clear site cookies for your Pane View hostname and retry.

Sync tokens are **not** used on the login form. Enter those in Lockstep only.

## Missing media after sync

**Symptom:** Files visible in Frame View but absent in Pane View.

**Fix:**

1. Run Lockstep **Plan**. Do uploads still appear pending?
2. **Push** if needed and wait for completion.
3. Browse the exact folder path, since renames change remote paths.
4. If you deleted the item in Pane View, push again to restore it.
5. Hard refresh the browser.

Pane View never shows unsynced local-only files.

## Thumbnails or previews blank

**Symptom:** Grid cells empty or viewer shows broken image icon.

**Fix:**

- Wait briefly. Thumbnails and previews are made the first time they are requested, and tiles retry on their own while they render.
- Click **Refresh** in the floating toolbar.
- Confirm push succeeded without file errors in Lockstep's **Log** tab.
- Try another browser (extensions can block cross-origin media).

## Video will not play

**Symptom:** Spinner forever or codec error.

**Fix:**

- Confirm the original plays locally in Frame View.
- Retry on Wi-Fi; large files struggle on poor mobile links.
- Re-push if the upload was interrupted mid-file.

## Search misses known files

**Fix:**

- Press Enter after typing; search does not run as you type.
- Search is library-wide, so recursive mode does not change search scope.
- Check spelling and underscores vs spaces in path segments.
- Push again. Each file is searchable as soon as its upload completes.
