# Quick start

This is the fastest way to see the full Latch Works loop working. You can refine folders, profiles, and settings later.

## 1. Collect something

1. Install [Gather Box](/docs/gather-box/install) in Chrome (build, then load `apps/gather-box/dist`).
2. Open a supported media or story page (see [Supported sources](/docs/supported-sources)).
3. Open the side panel, choose a destination folder, and start the download.
4. Wait for progress to finish and check the **Run log** for any failed files.

## 2. Browse locally

1. Open [Oriel](/docs/oriel) in **View** mode.
2. Click **Open** and select the archive root where Gather Box saved files.
3. Browse the grid, open a few items in the viewer, and confirm folders look right.
4. Optionally switch to **Tidy**, add the same folder, and see what it finds. Nothing changes until you ask.

## 3. Plan and push

1. Switch Oriel to [Sync](/docs/oriel/sync) and add a profile with your archive folder, Pane View API URL, and sync token (from your Pane View operator).
2. Run **Check connection** from the **…** menu, then **Plan** to see what would upload, update, and delete without changing anything.
3. When the plan looks right, run **Push** to upload changed originals.

## 4. View remotely

1. Sign in to [Pane View](/docs/pane-view).
2. Browse the same folder paths you synced.
3. Open media in the viewer and confirm thumbnails and previews load.

## What to do next

- Read [Archive organization](/docs/archive-organization) before your archive grows large.
- Plan without pushing until you trust the diff summary. [Plan](/docs/oriel/sync#plan) never writes.
- Run [Check connection](/docs/oriel/sync#check-connection) after changing folders or tokens.
