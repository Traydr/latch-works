# Quick start

This is the fastest way to see the full Latch Works loop working. You can refine folders, profiles, and settings later.

## 1. Collect something

1. Install [Gather Box](/docs/gather-box/install) in Chrome (build, then load `apps/gather-box/dist`).
2. Open a supported media or story page (see [Supported sources](/docs/supported-sources)).
3. Open the side panel, choose a destination folder, and start the download.
4. Wait for progress to finish and check the results log under **More** for any skipped files.

## 2. Browse locally

1. Open [Frame View](/docs/frame-view).
2. Choose **Open folder** and select the archive root where Gather Box saved files.
3. Browse the grid, open a few items in the viewer, and confirm folders look right.

## 3. Plan and push

1. Open [Lockstep](/docs/lockstep) and create a profile with your archive folder, Pane View API URL, and sync token (from your Pane View operator).
2. Click **Test connection**, then run **Plan** to see upload, update, keep, and delete counts without changing anything.
3. When the plan looks right, run **Push** to upload changed originals.

## 4. View remotely

1. Sign in to [Pane View](/docs/pane-view).
2. Browse the same folder paths you synced.
3. Open media in the viewer and confirm thumbnails and previews load.

## What to do next

- Read [Archive organization](/docs/archive-organization) before your archive grows large.
- Keep [Plan](/docs/lockstep/plan) read-only until you trust the diff summary.
- Use [Test connection / verify](/docs/lockstep/verify-and-doctor) after changing folders or tokens (verify is CLI-only).
