# Lockstep CLI companion

The desktop app covers everyday sync. The CLI companion runs the same engine headlessly for automation or remote shells.

## When to use it

- Scheduled plan-only reports
- Push from a machine without opening the desktop UI
- CI-style verify steps against a snapshot file

For most personal use, prefer the desktop app for visibility into progress and errors.

## Commands

| Command | Purpose |
| --- | --- |
| `plan` | Read-only diff summary |
| `push` | Upload and register new/changed originals (never deletes) |
| `prune` | Apply planned remote deletes |
| `verify` | Compare tree to snapshot |
| `doctor` | Environment and connectivity checks |

Push and prune are separate commands — same split as **Push uploads/updates** and **Apply deletes** in the desktop app.

Run commands with your source folder, Pane View URL, and token supplied via config file or environment — whichever your install documents.

## Configuration

A JSON config file in your home directory can store default source paths and API URLs. **Keep tokens in environment variables**, not in the config file on disk, so secrets stay out of backups and dotfile repos.

## Interactive mode

When run in a terminal without required arguments, Lockstep may prompt for missing source path, URL, and token. Useful for ad hoc runs on a new machine.

## Safety

- Always plan before push in automation scripts.
- Run prune only when you intend to apply delete entries from the plan.
- Use non-interactive confirm flags only after you trust the plan output.
- Doctor before the first automated push to a new remote library.
