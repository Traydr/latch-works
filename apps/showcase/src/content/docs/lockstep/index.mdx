# Lockstep

Lockstep is the sync bridge between your local archive and Pane View. It scans your source folder, shows what would change, and uploads originals only when you push.

![Lockstep desktop sync client](/screenshots/lockstep/plan.png)

## Role in the workflow

1. You organize and verify media in Frame View.
2. Lockstep **plans** a diff against your remote library (read-only).
3. You **push** when upload and update counts look right.
4. Pane View indexes what arrives for remote browsing.

Lockstep never syncs silently in the background.

## Desktop first

The Lockstep desktop app is the primary experience. The window has **Dashboard**, **Plan**, and **Log** tabs above a command dock with the stages **Profile**, **Plan**, **Review**, **Push**, and **Prune**, plus a **Doctor** button.

An optional command-line companion exists for scripted runs. See [Lockstep CLI](/docs/lockstep/cli).

## Core actions

| Action | Surface | Writes? | Purpose |
| --- | --- | --- | --- |
| Plan | Desktop + CLI | No | Show upload, update, keep, and delete counts |
| Push | Desktop + CLI | Yes | Upload and register new/changed originals only |
| Prune | Desktop + CLI | Yes | Remove remote entries that no longer exist locally |
| Doctor | Desktop + CLI | No | Validate profile settings and reachability |
| Verify | CLI only | No | Compare local tree to a snapshot file |
