# Latch Works overview

Latch Works is a private media archive toolchain. You collect media from the web, browse and verify it locally, sync changes intentionally to your remote library, and view the same folders privately on the web.

## The pipeline

1. **Gather Box** collects images, videos, and story PDFs from supported pages into folders on your computer.
2. **Oriel** is the desktop app: its **View** mode browses the archive on disk, **Tidy** removes duplicates and junk and converts files, and **Sync** compares the archive to your remote library and pushes changed originals when you choose.
3. The **Lockstep CLI** runs the same plan and push from a terminal, for scripts and schedules.
4. **Pane View** is the authenticated web gallery for browsing synced media on desktop, iPad, and iPhone.

```
Gather → Organize → Sync → View
```

## Who each tool is for

| Tool | Best for |
| --- | --- |
| Gather Box | Saving galleries, videos, and long-form stories while you browse |
| Oriel | Day-to-day local browsing, tidying the archive, and pushing updates on your schedule |
| Lockstep CLI | Scripted plans, capped pushes, and drift checks against a snapshot |
| Pane View | Private remote access without exposing a public gallery |

## Principles

- **Local-first:** the folder on your computer stays the source of truth.
- **Explicit sync:** nothing uploads until you run **Push** in Oriel's Sync mode, and deletes need a separate **Prune**.
- **Private delivery:** Pane View serves media through signed links that expire, not open URLs.
