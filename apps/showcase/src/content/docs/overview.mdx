# Latch Works overview

Latch Works is a private media archive toolchain. You collect media from the web, browse and verify it locally, sync changes intentionally to your remote library, and view the same folders privately on the web.

## The pipeline

1. **Gather Box** collects images, videos, and story PDFs from supported pages into folders on your computer.
2. **Frame View** is the desktop gallery for browsing and verifying the archive on disk.
3. **Lockstep** compares your local archive to your remote library and explicitly pushes changed originals when you choose.
4. **Pane View** is the authenticated web gallery for browsing synced media on desktop, iPad, and iPhone.

```
Gather → Organize → Sync → View
```

## Who each tool is for

| Tool | Best for |
| --- | --- |
| Gather Box | Saving galleries, videos, and long-form stories while you browse |
| Frame View | Day-to-day local browsing, comic reading, and archive checks |
| Lockstep | Reviewing what would change and pushing updates on your schedule |
| Pane View | Private remote access without exposing a public gallery |

## Principles

- **Local-first** — the folder on your computer stays the source of truth.
- **Explicit sync** — nothing uploads silently; Lockstep always shows a plan before writes.
- **Private delivery** — Pane View serves thumbnails and previews through signed links, not open URLs.
