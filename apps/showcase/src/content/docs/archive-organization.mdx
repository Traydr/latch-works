# Archive organization

A consistent folder layout makes Oriel's browsing, tidying, and planning and Pane View's navigation all feel like the same library.

## Pick one archive root

Choose a single top-level folder as your archive root. Point Oriel's View, Tidy, and Sync at that root (or at meaningful subtrees inside it). Gather Box can write into subfolders beneath the same root.

Keeping one root avoids surprises when Sync compares paths to your remote library.

## Media types

| Type | Typical layout | Viewing |
| --- | --- | --- |
| Image galleries | Folder of images (site or CDN filenames) | Grid or Comic mode |
| Videos | Single file or mixed grid with images | Viewer with playback controls |
| Comics | Folder of images (Comic mode groups the folder) | Comic reader in Oriel and Pane View |
| Stories | Single PDF per work in a dedicated folder | Pane View PDF reader after sync (Oriel does not open PDFs) |

## How Gather Box names things

Gather Box infers folders from the page you are on. Patterns vary by source. See [Supported sources](/docs/supported-sources) for the full matrix.

- **Media** lands in a creator folder (X, pixiv) or, for Reddit galleries, a post folder. Filenames are usually original or CDN names.
- **Story downloads** become one `Author-Story.pdf` **directly in the chosen root** (no nested site folder).
- Spaces in names become underscores for safe paths.

You can still reorganize after download. Just plan again before the next push.

## Comics and sequential folders

A **comic** is a folder of images. Enable **Comic** mode in Oriel's View or in Pane View to collapse those folders into comic entries.

Page order uses numeric-aware sorting. Zero-padded names (`001`, `002`, and so on) remain a good habit for consistency.

## Stories as PDFs

Long-form story collectors produce one PDF per work. Store them in dedicated story folders so they do not mix with image galleries in the same directory.

## Manual organization tips

- Keep site or creator at higher folder levels; keep individual posts in leaf folders.
- Avoid duplicate folder names at the same level when you care about remote path clarity.
- Tidy's **Move to…** and **Rename** keep an Undo, where the file manager does not.
- After large reorganizations, run Sync's **Plan** before **Push**. Moved files show up as deletes at the old path plus uploads at the new one.
