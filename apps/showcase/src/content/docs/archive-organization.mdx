# Archive organization

A consistent folder layout makes Frame View browsing, Lockstep planning, and Pane View navigation all feel like the same library.

## Pick one archive root

Choose a single top-level folder as your archive root. Point Frame View and Lockstep at that root (or at meaningful subtrees inside it). Gather Box can write into subfolders beneath the same root.

Keeping one root avoids surprises when Lockstep compares paths to your remote library.

## Media types

| Type | Typical layout | Viewing |
| --- | --- | --- |
| Image galleries | Folder of images (site or CDN filenames) | Grid or Comic mode |
| Videos | Single file or mixed grid with images | Viewer with playback controls |
| Comics | Folder of images (Comic mode groups the folder) | Comic reader in Frame View and Pane View |
| Stories | Single PDF per work in a dedicated folder | Pane View PDF reader after sync; Frame View PDF support is planned |

## How Gather Box names things

Gather Box infers folders from the page you are on. Patterns vary by source — see [Supported sources](/docs/supported-sources) for the full matrix.

- **Media posts** often land in creator/post folders; filenames are usually original or CDN names.
- **Story downloads** become one `Author-Story.pdf` **directly in the chosen root** (no nested site folder).
- Spaces in names become underscores for safe paths.

You can still reorganize after download — just plan again before the next push.

## Comics and sequential folders

A **comic** is a folder of images. Enable **Comic** mode in Frame View or Pane View to collapse those folders into comic entries.

Page order uses numeric-aware sorting. Zero-padded names (`001`, `002`, …) remain a good habit for consistency.

## Stories as PDFs

Long-form story collectors produce one PDF per work. Store them in dedicated story folders so they do not mix with image galleries in the same directory.

## Manual organization tips

- Keep site or creator at higher folder levels; keep individual posts in leaf folders.
- Avoid duplicate folder names at the same level when you care about remote path clarity.
- After large reorganizations, run Lockstep **Plan** before **Push** so you see moves as deletes plus uploads or new paths.
