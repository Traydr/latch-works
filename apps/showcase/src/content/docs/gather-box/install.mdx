# Install Gather Box

Gather Box runs as an unpacked Chrome extension during personal use. You need Google Chrome or a Chromium browser with extension support.

## Load the extension

1. Open `chrome://extensions` in Chrome.
2. Enable **Developer mode** (toggle in the toolbar).
3. Click **Load unpacked**.
4. Select the built extension folder from your Gather Box install.

After loading, pin Gather Box to the toolbar for quick access.

## First launch checks

1. Click the Gather Box icon on any tab — the popup should open without errors.
2. Visit a [supported page](/docs/supported-sources) — the popup should enable download.
3. Open **Extension options** from the popup or extensions page to review credential and folder defaults.

![Gather Box detecting a supported page](/screenshots/gather-box/popup-active.png)

## Optional: side panel and shortcuts

Gather Box can open a side panel for status while you browse. A default keyboard shortcut downloads from the active tab:

- **Mac:** Command+Shift+G
- **Windows / Linux:** Ctrl+Shift+G

Change the shortcut under `chrome://extensions/shortcuts` if it conflicts with other tools.

## Updating after changes

When you receive a new build, click **Reload** on the extension card in `chrome://extensions`, then retry a small test download.
