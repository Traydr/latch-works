# Install Gather Box

Gather Box runs as an unpacked Chrome extension. You need Google Chrome **145+** (or a Chromium browser that meets that floor).

## Build and load

1. From the Latch Works repo, build the extension:

   ```bash
   pnpm --filter @latch-works/gather-box build
   ```

2. Open `chrome://extensions` in Chrome.
3. Enable **Developer mode**.
4. Click **Load unpacked**.
5. Select `apps/gather-box/dist`.

After loading, pin Gather Box to the toolbar. Clicking the icon opens the **side panel** (there is no separate popup UI).

## First launch checks

1. Click the Gather Box icon — the side panel should open without errors.
2. Visit a [supported page](/docs/supported-sources) — download should enable.
3. Open **Settings** from the side panel (or the extension’s options page) to review credential and folder defaults.

![Gather Box side panel detecting a supported page](/screenshots/gather-box/sidepanel-active.png)

## Shortcuts

Default shortcuts (change under `chrome://extensions/shortcuts`):

| Action | Mac | Windows / Linux |
| --- | --- | --- |
| Toggle side panel | Command+Shift+. (Period) | Ctrl+Shift+. |
| Download from active tab | Command+Shift+, (Comma) | Ctrl+Shift+, |

On supported pages you can also use Right Shift+`]` / `[` for page shortcuts when enabled in Settings.

## Updating after changes

When you rebuild, click **Reload** on the extension card in `chrome://extensions`, then retry a small test download.
