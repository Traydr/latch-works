# Gather Box

Gather Box is a Chrome extension that saves image galleries and story PDFs from supported pages into folders on your computer. It is the **collect** step in the Latch Works pipeline.

![Gather Box popup ready to download](/screenshots/gather-box/popup.png)

## Role in the workflow

1. You browse a supported post or work page.
2. Gather Box detects the page type and prepares a download list.
3. Files land in inferred folders beneath the destination you choose.
4. Frame View browses those folders locally; Lockstep syncs them when you push.

Gather Box does not upload anything to Pane View by itself.

## What it collects

- **Galleries** — numbered original images in a post folder.
- **Stories** — one PDF per work (including multi-chapter merges where supported).

Supported sites are listed only in [Supported sources](/docs/supported-sources). Other pages appear as unsupported in the popup.

## Before you collect

- Pick an archive root on disk and reuse it across sessions.
- Stay signed in on sites that require login for story downloads.
- Confirm the popup shows a supported page before starting.
