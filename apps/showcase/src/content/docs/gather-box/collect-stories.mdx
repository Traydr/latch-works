# Collect stories as PDF

Story collectors produce a **single PDF** per work — suitable for offline reading in Frame View and Pane View.

## Supported story sources

Story collectors save long-form works as PDFs. See [Supported sources](/docs/supported-sources) for which sites support stories versus galleries.

## Steps

1. Open the work or story URL while signed in if the site requires it.
2. Open Gather Box and choose a destination folder (often a site-specific subfolder of your archive).
3. Start the download and wait for PDF generation to finish.
4. Confirm the output file appears in the results log.

## Output naming

Story PDFs typically use `{author}-{title}.pdf` with spaces replaced by underscores. Multi-chapter works merge into one file in reading order when the collector supports it.

## Credentials and login

Story sites often need your browser session. Gather Box can include credentials on download requests when allowed in extension settings:

- **Automatic** for some sites by default
- **Per-site** overrides in extension options
- **Never** if you want downloads to fail rather than send cookies

If a download returns login HTML instead of content, sign in on the site and retry.

## After download

Open the PDF in Frame View to verify formatting. Large multi-chapter works may take longer to build — wait for the popup to report completion before closing the tab.
