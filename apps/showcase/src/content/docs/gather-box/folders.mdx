# Destination folders

Gather Box writes into folders you select with the browser’s folder picker. Good defaults keep your archive browsable without manual renaming.

## Per-site vs global memory

By default each supported site remembers its own last destination folder. Switching sites does not overwrite another site’s choice.

In Settings you can enable **one global archive folder** so every collector reuses the same root. **Clear** in the side panel forgets the remembered folder.

When you collect from a new site for the first time (or with global mode off), pick a subfolder under your archive root that matches how you want Oriel to group that source.

## Profiles

A **profile** is a named set of remembered folders. The **Profile** picker at the top of the side panel switches between them, and **Manage** opens Settings, where profiles are added, renamed, and deleted. Each profile keeps its own global and per-site folders, so switching profiles switches where downloads land. Folders remembered before profiles existed belong to the **Default** profile, which can be renamed but not deleted. A queued page keeps the profile that was active when it was gathered.

## Inferred paths

Collectors build subpaths from page metadata. Exact templates live in [Supported sources](/docs/supported-sources). In short:

| Pattern | Examples |
| --- | --- |
| Creator folder | X `username`; pixiv `username-id` |
| Conditional folder | Reddit: direct file for single media; post folder for galleries |
| Direct file | Story PDFs land in the chosen root with no nested site folder |

Spaces become underscores. Adjust locally after download if you prefer different names, then run Sync's **Plan** before the next push.

## Writable folder validation

Gather Box checks that the active tab is supported and that you granted write access to the destination before starting. If permission expired, choose the folder again when prompted.

## Organization practices

- Keep one archive root; use first-level folders for sources or creators.
- Do not mix story PDFs and image galleries in the same leaf folder.
- After bulk collection, spot-check in Oriel's View, and let Tidy find duplicates, before syncing.
