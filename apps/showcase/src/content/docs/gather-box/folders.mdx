# Destination folders

Gather Box writes into folders you select with the browser’s folder picker. Good defaults keep your archive browsable without manual renaming.

## Per-site vs global memory

By default each supported site remembers its own last destination folder. Switching sites does not overwrite another site’s choice.

In Settings you can enable **one global archive folder** so every collector reuses the same root.

When you collect from a new site for the first time (or with global mode off), pick a subfolder under your archive root that matches how you want Frame View to group that source.

## Inferred paths

Collectors build subpaths from page metadata. Exact templates live in [Supported sources](/docs/supported-sources). In short:

| Pattern | Examples |
| --- | --- |
| Single folder | MyHentaiGallery comic title; X username; pixiv `username-id` |
| Nested folders | Kemono service/user/post; FANBOX creator/post |
| Conditional folder | Reddit: direct file for single media; post folder for galleries |
| Direct file | Story PDFs land in the chosen root with no nested site folder |

Spaces become underscores. Adjust locally after download if you prefer different names — then run Lockstep **Plan** before the next push.

## Writable folder validation

Gather Box checks that the active tab is supported and that you granted write access to the destination before starting. If permission expired, choose the folder again when prompted.

## Organization practices

- Keep one archive root; use first-level folders for sources or creators.
- Do not mix story PDFs and image galleries in the same leaf folder.
- After bulk collection, spot-check in Frame View before syncing.
