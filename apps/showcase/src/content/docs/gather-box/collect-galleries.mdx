# Collect image galleries

Gallery collectors download original images from a post page into a folder with sequential filenames.

## Steps

1. Open a supported gallery post in Chrome.
2. Click the Gather Box icon and confirm the page is recognized.
3. Click **Choose folder** (or reuse the remembered destination for that site).
4. Click **Download Content**.
5. Watch the progress bar and review the results log when finished.

## What to expect

- Images save as numbered files (`001.webp`, `002.webp`, …) in a post-specific folder.
- Nested paths vary by site (creator name, post title, user type). See [Supported sources](/docs/supported-sources) for patterns.
- Individual file failures are logged; the rest of the batch continues.

## Choosing the destination

Pick a folder inside your archive root so Frame View and Lockstep see the same tree later. Gather Box remembers the last folder **per site**, not one global folder for everything.

The popup shows the folder **name** only — browsers do not expose the full disk path for privacy reasons.

## Tips

- Collect one post at a time for predictable folder names.
- After download, open the folder in Frame View to confirm image order and count.
- If thumbnails on the site differ from originals, Gather Box targets original URLs where the collector supports it.
