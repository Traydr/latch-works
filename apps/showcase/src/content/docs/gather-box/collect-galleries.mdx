# Collect media

Media collectors download original images (and video on some sites) from a post or artwork page into folders under your chosen destination.

## Steps

1. Open a supported media page in Chrome.
2. Open the Gather Box side panel and confirm the page is recognized.
3. Click **Choose** (or reuse the remembered destination for that site).
4. Click **Download Content**.
5. Watch progress; open **More** for the results log, **Retry failed**, or **Copy errors** if needed.

You can also right-click a supported page and choose **Gather to archive**, or use the download keyboard shortcut.

## Queue while browsing

If Gather Box is already processing an output, its main action changes to **Add to Queue**. Add the
current page, wait for the queued confirmation, and then continue browsing. Gather Box only needs the
page during the short metadata-capture step; downloads and AVIF conversion continue one output at a
time in the background.

Fully captured queue entries persist across browser restarts. If folder permission expires, the
queue pauses and the side panel names the page that can confirm it — any supported page when you use
one global folder, otherwise a page from the paused entry's own site. Gathering from that page
confirms access, resumes the paused entry, and queues the page you gathered from as well.

## What to expect

- Filenames usually come from the site or CDN. Gather Box does not renumber every gallery to `001`, `002`, ….
- Reddit multi-image posts use `01_<filename>` style prefixes inside a post folder.
- Nested paths vary by site — see [Supported sources](/docs/supported-sources).
- Individual file failures are logged; the rest of the batch continues.
- Identical files are skipped; collisions get a short suffix before the extension.

## Choosing the destination

Pick a folder inside your archive root so Frame View and Lockstep see the same tree later.

By default Gather Box remembers the last folder **per site**. In Settings you can instead use **one global archive folder** for every site.

The side panel shows the folder **name** only — browsers do not expose the full disk path for privacy reasons.

## Tips

- Queue several posts while browsing; each keeps the folder name captured from its source page.
- After download, open the folder in Frame View to confirm count and order.
- Use **Cancel run** if you need to stop a long download.
