# Gather Box troubleshooting

## Unsupported page

**Symptom:** Download button disabled; side panel says the page is not supported.

**Fix:**

- Confirm the URL matches a [supported source](/docs/supported-sources) pattern (post/artwork/work page, not search or profile index).
- Reload the tab after the page fully loads.
- Reload the extension if you just updated it.

## Folder permission errors

**Symptom:** Download fails immediately or asks for folder access repeatedly.

**Fix:**

- Choose the destination folder again and grant write permission.
- Avoid folders on read-only or synced cloud drives if the browser blocks writes.
- Pick a local disk path inside your archive root.

## Partial download / missing files

**Symptom:** Progress completes but some files are missing from the log or folder.

**Fix:**

- Open **More** and read the results log for per-file errors.
- Use **Retry failed** for transient network errors.
- Ensure you are on the full post, not a preview or listing page.

## Login or session issues

**Symptom:** Story PDF is empty, tiny, or contains a login page.

**Fix:**

- Sign in on the site in the same browser profile as the extension.
- In Gather Box Settings, allow credentials for that site (or set mode to **Always** temporarily).
- Re-open the work page and download again.

## Side panel errors or stale state

**Fix:**

- Close and reopen the side panel.
- Reload the extension from `chrome://extensions`.
- Try the download shortcut (Command/Ctrl+Shift+Comma) on the active tab.
- Use the context menu **Gather to archive** on the page URL as a fallback.
