# Keyboard shortcuts

Shortcuts are plain key presses unless noted. They are disabled while typing in text fields. In Oriel, `Cmd` is `Ctrl` off macOS, and **?** shows the current mode's shortcut sheet.

## Oriel: everywhere

| Keys | Action |
| --- | --- |
| Cmd+1 / Cmd+2 / Cmd+3 | Switch to View, Tidy, or Sync |
| Cmd+O | Open a folder (View) or add one (Tidy) |
| Cmd+R | Refresh (View) or rescan (Tidy) |
| Cmd+, | Settings |
| Cmd+\ | Collapse or expand the sidebar |
| ? | Keyboard shortcuts |

## Oriel View: gallery

| Keys | Action |
| --- | --- |
| W / A / S / D or Arrow keys | Move grid focus |
| Enter / F | Open selected item |
| Shift+W | Go to parent folder |
| Shift+S | Open selected / first folder |
| Shift+A / Shift+D | Previous / next sibling folder |

## Oriel View: viewer

| Keys | Action |
| --- | --- |
| Q / Arrow Left | Previous item |
| E / Arrow Right | Next item |
| Escape | Close viewer |
| Space / 2 | Play or pause video |
| 1 / 3 | Seek backward / forward 5s |
| Hold 4 | Temporary playback speed boost (2×) |
| M | Mute or unmute video |

## Oriel View: comic reader

| Keys | Action |
| --- | --- |
| Q / Arrow Left | Previous page |
| E / Arrow Right | Next page |
| Escape | Close reader |

## Oriel Tidy

| Keys | Action |
| --- | --- |
| Opt+Cmd+1 to 7 | Overview, Duplicates, Convert, Clean up, Library, History, Holding |
| Cmd+Return | The page's main action: Tidy up, Convert, Clean up, or Shrink |
| Cmd+Z | Undo the last change |
| Cmd+F or / | Search the Library |
| Return | Duplicates: keep the suggestion. Library: rename |
| 1 to 9 / Shift+1 to 9 | Duplicates: keep only this version / keep it as well |
| N / S | Duplicates: keep all / skip the set |
| Space | Duplicates: look closer. Library: Quick Look |
| P | Duplicates: prefer this version's folder |
| I | Library: show or hide the Inspector |
| Cmd+Delete | Library: move to Holding. Holding: restore |
| Shift+Cmd+M | Library: Move to… |
| Shift+Cmd+Delete | Holding: empty to Trash |
| U | History: undo the selected change |

## Oriel Sync

| Keys | Action |
| --- | --- |
| / | Filter the plan by path |
| Cmd+L | Show or hide the run log |

Sync is worked with its buttons, so it has only these keys.

## Pane View: gallery and viewer

Pane View mirrors Oriel's View navigation for grid and viewer actions:

| Keys | Action |
| --- | --- |
| W / A / S / D or Arrow keys | Move grid focus |
| Enter / F | Open selected item |
| Shift+W | Go to parent folder |
| Shift+S | Open focused folder |
| Shift+A / Shift+D | Previous / next sibling folder |
| Q / E or Arrow Left / Right | Previous / next media (page in the comic reader) |
| Space / 2 | Play or pause video |
| 1 / 3 | Seek backward / forward 5s |
| Hold 4 | Temporary speed boost (2×) |
| Escape | Close viewer or overlay |
| ? | Show shortcuts overlay (gallery only) |
| Cmd/Ctrl+B | Show or hide the sidebar |

## Gather Box

| Keys | Action |
| --- | --- |
| Cmd/Ctrl+Shift+. (Period) | Toggle side panel |
| Cmd/Ctrl+Shift+, (Comma) | Download from active tab |
| Right Shift+`]` | Toggle side panel (on supported pages) |
| Right Shift+`[` | Download from the page (on supported pages) |
| Enter (in the side panel) | Start download |

Change the Cmd/Ctrl shortcuts under `chrome://extensions/shortcuts`. The Right Shift page shortcuts are on by default and can be turned off in Gather Box Settings.
