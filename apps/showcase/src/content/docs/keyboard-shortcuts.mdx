# Keyboard shortcuts

Shortcuts are plain key presses unless noted. They are disabled while typing in text fields.

## Frame View — gallery

| Keys | Action |
| --- | --- |
| W / A / S / D or Arrow keys | Move grid focus |
| Enter / F | Open selected item |
| Shift+W | Go to parent folder |
| Shift+S | Open focused folder |
| Shift+A / Shift+D | Previous / next sibling folder |

## Frame View — viewer

| Keys | Action |
| --- | --- |
| Q / Arrow Left | Previous item |
| E / Arrow Right | Next item |
| Escape | Close viewer |
| Space / 2 | Play or pause video |
| 1 / 3 | Seek backward / forward |
| 4 | Temporary playback speed boost |

## Frame View — comic reader

| Keys | Action |
| --- | --- |
| Q / Arrow Left | Previous page |
| E / Arrow Right | Next page |
| Escape | Close reader |

## Pane View — gallery and viewer

Pane View mirrors Frame View navigation for grid and viewer actions:

| Keys | Action |
| --- | --- |
| W / A / S / D or Arrow keys | Move grid focus |
| Enter / F | Open selected item |
| Shift+W | Go to parent folder |
| Shift+S | Open focused folder |
| Shift+A / Shift+D | Previous / next sibling folder |
| Q / E | Previous / next media in viewer |
| Space / 2 | Play or pause video |
| Escape | Close viewer or overlay |
| ? | Show shortcuts overlay |

## Gather Box

| Keys | Action |
| --- | --- |
| Command+Shift+G (Mac) / Ctrl+Shift+G | Download from active tab |

You can change the shortcut in Chrome’s extension keyboard shortcuts page.

## Lockstep

Lockstep desktop is primarily mouse-driven: **Plan**, **Push uploads/updates**, and **Apply deletes** are separate dock actions. The optional command-line companion uses subcommands by name — see [Lockstep CLI](/docs/lockstep/cli).
