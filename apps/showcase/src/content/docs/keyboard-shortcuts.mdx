# Keyboard shortcuts

Shortcuts are plain key presses unless noted. They are disabled while typing in text fields.

## Frame View: app menu

| Keys | Action |
| --- | --- |
| Cmd/Ctrl+O | Open folder |
| Cmd+R (macOS) / F5 (Windows, Linux) | Refresh / rescan |
| Cmd/Ctrl+, | Open settings |

## Frame View: gallery

| Keys | Action |
| --- | --- |
| W / A / S / D or Arrow keys | Move grid focus |
| Enter / F | Open selected item |
| Shift+W | Go to parent folder |
| Shift+S | Open selected / first folder |
| Shift+A / Shift+D | Previous / next sibling folder |

## Frame View: viewer

| Keys | Action |
| --- | --- |
| Q / Arrow Left | Previous item |
| E / Arrow Right | Next item |
| Escape | Close viewer |
| Space / 2 | Play or pause video |
| 1 / 3 | Seek backward / forward 5s |
| Hold 4 | Temporary playback speed boost (2×) |
| M | Mute or unmute video |

## Frame View: comic reader

| Keys | Action |
| --- | --- |
| Q / Arrow Left | Jump to previous page |
| E / Arrow Right | Jump to next page |
| Escape | Close reader |

## Pane View: gallery and viewer

Pane View mirrors Frame View navigation for grid and viewer actions:

| Keys | Action |
| --- | --- |
| W / A / S / D or Arrow keys | Move grid focus |
| Enter / F | Open selected item |
| Shift+W | Go to parent folder |
| Shift+S | Open focused folder |
| Shift+A / Shift+D | Previous / next sibling folder |
| Q / E or Arrow Left / Right | Previous / next media (page in the comic reader) |
| Space / 2 | Play or pause video |
| 1 / 3 | Seek backward / forward 5s |
| Hold 4 | Temporary speed boost (2×) |
| Escape | Close viewer or overlay |
| ? | Show shortcuts overlay (gallery only) |
| Cmd/Ctrl+B | Show or hide the sidebar |

## Gather Box

| Keys | Action |
| --- | --- |
| Cmd/Ctrl+Shift+. (Period) | Toggle side panel |
| Cmd/Ctrl+Shift+, (Comma) | Download from active tab |
| Right Shift+`]` | Toggle side panel (on supported pages) |
| Right Shift+`[` | Download from the page (on supported pages) |
| Enter (in the side panel) | Start download |

Change the Cmd/Ctrl shortcuts under `chrome://extensions/shortcuts`. The Right Shift page shortcuts are on by default and can be turned off in Gather Box Settings.

## Lockstep

Lockstep desktop has no keyboard shortcuts: **Plan**, **Push**, **Prune**, and **Doctor** are buttons in the command dock. The optional CLI uses named subcommands. See [Lockstep CLI](/docs/lockstep/cli).
