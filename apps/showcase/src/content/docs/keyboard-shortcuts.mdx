# Keyboard shortcuts

Shortcuts are plain key presses unless noted. They are disabled while typing in text fields.

## Frame View — app menu

| Keys | Action |
| --- | --- |
| Cmd/Ctrl+O | Open folder |
| F5 / Cmd+R | Refresh / rescan |
| Cmd/Ctrl+, | Open settings |

## Frame View — gallery

| Keys | Action |
| --- | --- |
| W / A / S / D or Arrow keys | Move grid focus |
| Enter / F | Open selected item |
| Shift+W | Go to parent folder |
| Shift+S | Open selected / first folder |
| Shift+A / Shift+D | Previous / next sibling folder |

## Frame View — viewer

| Keys | Action |
| --- | --- |
| Q / Arrow Left | Previous item |
| E / Arrow Right | Next item |
| Escape | Close viewer |
| Space / 2 | Play or pause video |
| 1 / 3 | Seek backward / forward (~5s) |
| Hold 4 | Temporary playback speed boost (2×) |

## Frame View — comic reader

| Keys | Action |
| --- | --- |
| Q / Arrow Left | Jump to previous page |
| E / Arrow Right | Jump to next page |
| Escape | Close reader |

## Pane View — gallery and viewer

Pane View mirrors Frame View navigation for grid and viewer actions:

| Keys | Action |
| --- | --- |
| W / A / S / D or Arrow keys | Move grid focus |
| Enter / F | Open selected item |
| Shift+W | Go to parent folder |
| Shift+S | Open focused folder |
| Shift+A / Shift+D | Previous / next sibling folder |
| Q / E | Previous / next media or comic page |
| Space / 2 | Play or pause video |
| 1 / 3 | Seek backward / forward |
| Hold 4 | Temporary speed boost |
| Escape | Close viewer or overlay |
| ? | Show shortcuts overlay |

## Gather Box

| Keys | Action |
| --- | --- |
| Cmd/Ctrl+Shift+. (Period) | Toggle side panel |
| Cmd/Ctrl+Shift+, (Comma) | Download from active tab |

Change shortcuts under `chrome://extensions/shortcuts`. Page shortcuts (Right Shift+`]` / `[`) can be enabled in Gather Box Settings.

## Lockstep

Lockstep desktop is primarily mouse-driven: **Plan**, **Push**, **Apply deletes**, and **Test connection** are dock actions. The optional CLI uses named subcommands — see [Lockstep CLI](/docs/lockstep/cli).
