# Glossary

| Term | Definition |
| --- | --- |
| Archive | Your folder tree of collected and organized media on disk |
| Source folder | The root directory Lockstep scans; usually your archive root |
| Original | Full-resolution file in the archive (image, video, or PDF) |
| Thumbnail | Small derived image for fast grid browsing |
| Preview | Larger derived image or clip for viewer loading |
| Plan | Read-only Lockstep diff: what would upload, update, keep, or delete |
| Push | Lockstep operation that uploads and registers new/changed originals (never deletes) |
| Apply deletes | Separate Lockstep action that removes remote entries listed in the plan |
| Verify | Compare local state to a saved remote snapshot for drift |
| Doctor | Health check for profile settings, token, and remote reachability |
| Comic | Folder of sequential images read in filename order |
| Story | Long-form work, usually saved as a single PDF |
| Signed link | Temporary URL for Pane View thumbnails and previews |
| Profile | Lockstep saved settings: name, source folder, Pane View URL, token |
| Recursive mode | Include subfolders when browsing or searching |
| Explicit sync | Uploads only when you run push after reviewing a plan |
