# Frame View preferences

Open the settings drawer from the gallery toolbar (or `Cmd/Ctrl+,`) to adjust usability and storage options.

![Frame View settings drawer](/screenshots/frame-view/settings.png)

## Usability

- **Theme** — System, Light, or Dark (persists across sessions).
- **Remember last folder** — reopen the previous archive root on launch.
- **Recursive by default** — start new folders in recursive mode.
- **Hover autoplay / viewer autoplay / loop videos / preview audio** — video playback behavior in the grid and viewer.
- **Loop viewer navigation** — wrap previous/next at the ends of the list.
- **Thumbnail size** and **show images / show videos** — what the grid displays.

## Keyboard shortcuts

The Hotkeys tab lists active shortcuts for gallery, viewer, and comic modes. A full table lives in [Keyboard shortcuts](/docs/keyboard-shortcuts).

## Local storage

Frame View maintains a local media index and thumbnail cache for fast rescans. From settings you can:

- Clear the thumbnail cache when previews look stale
- View media-index stats (item counts, database path) and clear the index if needed

Clearing cache or index does not delete originals — only derived data, which rebuilds on the next scan.

## Debug

The Debug tab exposes diagnostics for stubborn scan or index issues. Use it when normal clear-and-rescan does not help.

## Window state

Window size and maximized state restore on launch so your layout stays consistent.
