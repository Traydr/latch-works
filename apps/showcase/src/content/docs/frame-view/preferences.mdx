# Frame View preferences

Open the settings drawer from the gallery toolbar to adjust usability and storage options.

![Frame View settings drawer](/screenshots/frame-view/settings.png)

## Appearance

Switch between dark and light theme. The choice persists across sessions and matches your preferred reading environment.

## Remembered folders

Frame View stores recently opened paths so you can return to your archive root quickly. Clear history here if you relocate the archive to a new disk.

## Keyboard shortcuts

The settings drawer lists active hotkeys for gallery, viewer, and comic modes. A full table lives in [Keyboard shortcuts](/docs/keyboard-shortcuts).

## Storage and cache

Frame View maintains a local media index and thumbnail cache for fast rescans. From settings you can:

- Inspect cache location and size
- Clear thumbnail cache when previews look stale
- Trigger diagnostics if scans misbehave

Clearing cache does not delete originals — only derived thumbnails and index data, which rebuild on the next scan.

## Window state

Window size and maximized state restore on launch so your layout stays consistent.
