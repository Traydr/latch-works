# Comics and stories

Frame View treats comics and PDF stories as first-class reading modes on top of the same folder grid.

## Comics (image folders)

When a folder contains numbered sequential images, Frame View can present it as a **comic entry** instead of a loose pile of files.

- Open the comic to enter the reader with one image per page.
- Turn pages with **Q** / **E** or arrow keys.
- Press Escape to return to the gallery.

Filename order matters. Use zero-padded numbers (`001`, `002`, …) if lexical sorting puts `10` before `2`.

## PDF stories

PDF files from Gather Box or your own imports open in a dedicated reader with page navigation. Long works benefit from keyboard page turns similar to comics.

## Mixed folders

Keep stories (PDFs) separate from image galleries in the same directory when you want clean comic detection. See [Archive organization](/docs/archive-organization).

## Pane View parity

Pane View uses the same comic and PDF concepts for synced content. What reads well locally should read the same remotely after push.
