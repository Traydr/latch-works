# Comics and stories

Frame View treats image comics as a first-class reading mode when you enable **Comic** in the toolbar. PDF reading is planned, not shipped.

## Comics (image folders)

1. Toggle **Comic** in the gallery toolbar.
2. Frame View groups non-root folders that contain images into comic entries (no special “numbered sequence” detection required).
3. Comic mode forces recursive scanning and hides loose media tiles.
4. Open a comic to enter the reader — pages are stacked in a vertical scroll.
5. Jump between pages with **Q** / **E** (or arrows). Escape returns to the gallery.

Page order uses numeric-aware sorting, so `2` sorts before `10`. Zero-padded names (`001`, `002`, …) are still fine when you want predictable filenames.

## PDF stories

Frame View does not currently index or open PDFs. Use Pane View for PDF reading after sync. Keep story PDFs out of image comic folders so comic grouping stays clean.

## Pane View parity

Pane View supports comics and PDFs for synced content. Frame View’s comic reader is a vertical page stack; Pane View’s comic reader is closer to page-turn navigation. Hotkeys (Q/E, Escape) stay similar.
