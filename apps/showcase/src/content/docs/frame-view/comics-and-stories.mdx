# Comics and stories

Frame View treats image comics as a first-class reading mode. PDF reading is [planned](../../../../../../docs/plans/040-frame-view-pdf-spike.md), not shipped.

## Comics (image folders)

When a folder contains numbered sequential images, Frame View can present it as a **comic entry** instead of a loose pile of files.

- Open the comic to enter the reader with one image per page.
- Turn pages with **Q** / **E** or arrow keys.
- Press Escape to return to the gallery.

Filename order matters. Use zero-padded numbers (`001`, `002`, …) if lexical sorting puts `10` before `2`.

## PDF stories

Frame View does not currently index or open PDFs. The planned reader will be evaluated separately; use Pane View for PDF reading after sync.

## Mixed folders

Keep stories (PDFs) separate from image galleries in the same directory when you want clean comic detection once PDF support ships. See [Archive organization](/docs/archive-organization).

## Pane View parity

Pane View supports comics and PDFs for synced content. Frame View PDF support remains planned.
