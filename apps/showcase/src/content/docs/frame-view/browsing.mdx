# Browsing folders

Frame View turns a folder on disk into a virtualized grid of media entries.

## Open a folder

Use **Open folder** from the menu or the standard open shortcut for your platform. Frame View remembers recently opened paths.

Point at your archive root or any subtree — the breadcrumb and folder overlay reflect your current location.

## Grid navigation

- Click an item to select it; double-click or press Enter / F to open the viewer.
- Use W/A/S/D or arrow keys to move selection.
- Shift+S opens the focused folder; Shift+W goes to the parent.

Mixed grids show images and videos together. Video cells loop short previews so you can scan motion quickly.

## Recursive scanning

Enable recursive mode to include media from subfolders in the current view. Useful for flat searches across a creator tree without drilling down manually.

Large folders use a background scan and local index so scrolling stays responsive. The first scan after opening a big tree may take time — see [Troubleshooting](/docs/frame-view/troubleshooting).

## Sorting

Switch sort modes from the gallery toolbar — including name, date, and random shuffle. Sort affects grid order only, not files on disk.

## Folder overlay

Open the folder overlay to jump between sibling folders without returning to the file picker. Shift+A and Shift+D move to previous and next sibling folders.
