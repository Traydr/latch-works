# Frame View troubleshooting

## Missing media in grid

**Symptom:** Files exist on disk but do not appear.

**Fix:**

- Confirm you opened the correct folder or enable recursive mode.
- Wait for the scan progress indicator to finish.
- Check that files use supported image or video extensions. Frame View PDF support is planned, not shipped.
- Rescan from the menu after copying files in from outside Gather Box.

## Slow scans on large folders

**Symptom:** First open of a huge tree takes minutes.

**Fix:**

- Let the initial index complete — later visits reuse the local media index.
- Narrow to a subfolder when spot-checking new downloads.
- Clear and rebuild cache only if the index is corrupt, not for every slow folder.

## Stale or wrong thumbnails

**Symptom:** Grid previews show old frames or blank cells.

**Fix:**

- Clear thumbnail cache in settings and rescan.
- For videos, ensure the file is not locked by another program.

## Video will not play

**Symptom:** Black screen or immediate error in viewer.

**Fix:**

- Confirm the file plays in another player (codec support varies by platform).
- Try opening a neighboring file to isolate a corrupt download.
- Re-download from Gather Box if the original is incomplete.

## Comic page order wrong

**Symptom:** Pages appear shuffled.

**Fix:**

- Rename with consistent zero-padded numbering.
- Remove non-page images from the comic folder.
