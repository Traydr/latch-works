# Viewer controls

The viewer opens images and videos fullscreen over the gallery.

![Frame View media viewer](/screenshots/frame-view/viewer.png)

## Opening and closing

- Double-click a grid item or press Enter / F.
- Press Escape to close and return to the grid.
- Use **Reveal in folder** in the viewer chrome to show the file in your OS file manager.

## Image navigation

- **Q** or **Arrow Left** — previous item
- **E** or **Arrow Right** — next item

Navigation wraps within the current folder view only when **Loop viewer navigation** is enabled in preferences. Sort order and recursive settings still apply to what is in the list.

## Video playback

| Control | Keys |
| --- | --- |
| Play / pause | Space or 2 |
| Seek backward (~5s) | 1 |
| Seek forward (~5s) | 3 |
| Temporary speed boost (2×) | Hold 4 |

The on-screen bar also provides seek, volume, speed, and fullscreen toggles.

## Fullscreen

Use the viewer fullscreen control or your platform fullscreen shortcut (`View → Toggle Full Screen` in the app menu). Escape closes the viewer entirely — it does not leave fullscreen first.

## GIFs and large images

Still images scale to fit the viewport. Very large files may take a moment to decode — wait before skipping to the next item if the screen is blank.
