# Frame View

Frame View is the desktop gallery for your local archive. Browse mixed images and videos and read comics from image folders without uploading anything. PDF reading is planned, not shipped.

![Frame View gallery grid](/screenshots/frame-view/gallery.png)

## Role in the workflow

Frame View sits between **Gather** and **Sync**:

1. Gather Box writes new folders to disk.
2. Frame View lets you verify layout, order, and quality locally.
3. Lockstep pushes changes after you review a plan.
4. Pane View mirrors the synced tree for remote browsing.

## What you can do

- Open any folder on disk as your archive view (or drag a folder onto the window).
- Scan large trees with recursive folder mode.
- Play videos with rich controls in the viewer.
- Toggle **Comic** mode to group image folders into comic entries.
- PDF reading is planned; Frame View does not currently index or open PDFs.

Frame View is read-only — it does not rename or delete files for you. Organize files in the file manager and rescan.

Supported images include jpg, jpeg, png, webp, gif, and bmp. Supported video includes mp4, webm, mov, and mkv.
