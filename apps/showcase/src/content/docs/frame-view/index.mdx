# Frame View

Frame View is the desktop gallery for your local archive. Browse mixed images and videos, read comics from sequential folders, and open story PDFs — all without uploading anything.

![Frame View gallery grid](/screenshots/frame-view/gallery.png)

## Role in the workflow

Frame View sits between **collect** and **sync**:

1. Gather Box writes new folders to disk.
2. Frame View lets you verify layout, order, and quality locally.
3. Lockstep pushes changes after you review a plan.
4. Pane View mirrors the synced tree for remote browsing.

## What you can do

- Open any folder on disk as your archive view.
- Scan large trees with recursive folder mode.
- Play videos with rich controls in the viewer.
- Collapse image folders into comic entries.
- Read PDF stories in a dedicated reader.

Frame View is read-only — it does not rename or delete files for you, but you can organize files in the file manager and rescan.
